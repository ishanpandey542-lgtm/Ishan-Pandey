FOLDER STRUCTURE
- index.html       Redesigned university library landing page
- books.html       Dedicated library catalogue, search, department filters & reservations
- css/style.css    Navy & gold styling, responsive layout and animations
- js/books.js      Original book catalogue data (UNMODIFIED)
- js/app.js        Original search, filters, demo login/signup and reservations (UNMODIFIED)
- assets/          Existing university logo and media assets

HOW TO RUN
1. Extract this ZIP archive.
2. Open the lpu-library-redesign folder.
3. Open index.html in Chrome, Edge, or Firefox (or launch via VS Code Live Server).
4. Click "VISIT THE LIBRARY" to navigate to books.html and search, filter, log in, or reserve books.

JAVASCRIPT INTEGRITY
- js/books.js and js/app.js are completely unmodified (byte-for-byte identical to the original archive).
- All required IDs, classes, and interactive elements are preserved across index.html and books.html.

LOGOUT REDIRECT
- Clicking "Log out" on any page clears the demo session and redirects automatically to index.html.
